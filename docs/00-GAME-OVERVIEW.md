# Neon Dash — Game Overview

## Game Name

**Neon Dash**

## Genre

HTML5 Casual Endless Runner

## Platforms

- YouTube Playables
- CrazyGames
- Poki

## Target Audience

Casual players seeking short, repeatable sessions with low friction retry.

## Core Fantasy

**"How long can I survive?"**

## Core Loop

```
RUN → DODGE → FAIL → RETRY
```

## Primary Session Target

- **Primary run duration:** 30–120 seconds
- **Skilled players:** 120–180+ seconds
- **Design objective:** "One more run" — not maximum survival time

## Design Pillars

1. Player experience > technical elegance
2. Retention > feature count
3. Fairness > randomness
4. Simplicity > unnecessary complexity
5. Core gameplay > secondary systems
6. Difficulty from mastery, not unfair RNG
7. Feedback supports gameplay, never competes with it

## Product Goals

- Fast retry loop with minimal friction
- Fair, learnable obstacle patterns (future)
- Score-driven motivation with personal best tracking
- Portal-ready HTML5 build (YouTube Playables, CrazyGames, Poki)
- Configuration-driven tuning for rapid iteration

## Non-Goals (Current Phase)

- Full gameplay implementation
- Difficulty Director
- Pattern System
- Shield system
- Monetization
- Analytics integration
- Visual polish / art production
- Multiplayer or social features

## Current Development Phase

**Foundation / Pre-production**

Building clean, testable, documented architecture as the base for incremental gameplay tasks.
