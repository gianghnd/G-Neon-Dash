# ASOL GAME FACTORY — MASTER RULES

1. Player experience > technical elegance
2. Retention > feature count
3. Fairness > randomness
4. Simplicity > unnecessary complexity
5. No feature without a player problem
6. Product direction requires Game Director approval
7. Major changes require acceptance criteria
8. Every implementation produces a handoff
9. Major milestones require external review
10. Real player data > theoretical assumptions
11. Prefer reversible decisions during soft launch
12. Never silently change product direction
13. Never claim a feature is validated without evidence
14. Code quality does not equal product quality
